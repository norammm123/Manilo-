说明：
- 四张图都已经放进去了，页面直接就能显示，不需要额外操作。
- 想换图，保持同名覆盖即可（jpg / png 都支持；换扩展名要同步改 index.html 里的 src）。
- **版面：四栏并排一行**，顺序为 学生端 · 教师端 · 硬件成品 · 小程序。
- **四张图都完整显示、绝不裁切**，原理是三层配合：
    ① 网格列宽按各图片的宽高比分配（1.836 : 1.836 : 0.75 : 0.477）；
    ② 每个图框的 aspect-ratio 锁定为该图片自身的宽高比；
    ③ 图片使用 object-fit: contain。
  三者合起来 = 图片正好填满图框，既不裁切、也没有 letterbox 留白。
- 换图后如果宽高比变了，**必须同步改两个地方**，否则会出现留白或裁切：
    1) index.html 里 `.gal` 的 grid-template-columns 比例
    2) 对应 `.frame.shotv / .pic / .phone` 的 aspect-ratio
- 文件缺失时页面显示虚线占位框和补拍提示，不会报错。

截图是怎么来的（便于以后重拍）：
- 教师端：B 端自带演示数据，直接截 `http://127.0.0.1:5174/?demo=1`（1680×915 视口）。
- 学生端：Flask 模板脱离后端单独渲染，再注入一段「练习中」的状态
  （一句话 + 计时/次数 + 反馈列表）后截图；注意模板里的 `url_for('static', ...)`
  要替换成相对路径，且临时页面必须放在 web_deploy/ 下，否则队标加载不出来。
- 硬件：实拍照片，直接用。
